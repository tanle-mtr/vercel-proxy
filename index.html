支持仓库浏览 · Release 下载 · Raw 文件 · aria2c 多线程加速

🚀 快速开始 📖 使用指南
MIT License Vercel Ready Zero Dependencies
📦

仓库浏览

通过代理访问 GitHub 仓库页面，右下角自动出现"下载源码"按钮，一键获取整个仓库的压缩包。

⬇️

高速下载

Release 附件、Raw 文件、Archive 压缩包，所有下载请求通过 Vercel 边缘节点加速。

⚡

aria2c 加速

完美支持 aria2c 多线程下载，16 线程并发拉取，大文件下载速度提升 10 倍以上。

🔌

API 代理

直接代理 api.github.com，获取纯净 JSON 数据，可用于脚本自动化、CI/CD 流程集成。

🛡️

安全可靠

白名单域名限制，仅代理 GitHub 相关域名。零依赖设计，无第三方库风险。

💰

完全免费

基于 Vercel Hobby 计划，每月 100 万次请求、100GB 带宽，个人使用完全够用。

🚀 三步部署

1

克隆仓库

将项目克隆到你的 GitHub 账号下

git clone https://github.com/tanle-mtr/vercel-proxy
2

导入 Vercel

在 Vercel Dashboard 点击 Add New → Project，选择该仓库

查看详细步骤 →
3

开始使用

部署完成后，访问你的域名即可开始使用

https://your-domain.vercel.app/github.com/owner/repo

📝 使用方式

场景 URL 格式
📦 仓库浏览 /github.com/owner/repo
⬇️ Release 下载 /github.com/owner/repo/releases
📄 Raw 文件 /raw.githubusercontent.com/owner/repo/branch/file
📦 Archive /github.com/owner/repo/archive/main.zip
🔌 API /api.github.com/repos/owner/repo
⚡ aria2c aria2c -x 16 -s 16 "https://域名/.../main.zip"
