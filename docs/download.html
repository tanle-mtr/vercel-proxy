下载指南

本文档汇总了各种下载方式，覆盖命令行、脚本和浏览器场景。

cURL 下载

cURL 是最常用的下载工具，几乎所有系统都预装了。

下载 Archive（整个仓库）

# 下载 main 分支 curl -L "https://your-domain.vercel.app/github.com/owner/repo/archive/refs/heads/main.zip" -o repo.zip # 下载 master 分支 curl -L "https://your-domain.vercel.app/github.com/owner/repo/archive/refs/heads/master.zip" -o repo.zip # 下载指定 tag curl -L "https://your-domain.vercel.app/github.com/owner/repo/archive/refs/tags/v1.0.0.zip" -o repo-v1.zip # 下载 tar.gz 格式 curl -L "https://your-domain.vercel.app/github.com/owner/repo/archive/refs/heads/main.tar.gz" -o repo.tar.gz

下载 Raw 文件

# 下载单个文件 curl "https://your-domain.vercel.app/raw.githubusercontent.com/owner/repo/main/README.md" -o README.md # 下载并跟随重定向 curl -L "https://your-domain.vercel.app/raw.githubusercontent.com/owner/repo/main/large-file.bin" -o file.bin

下载 Release 附件

curl -L "https://your-domain.vercel.app/github.com/owner/repo/releases/download/v1.0.0/app-linux-amd64.zip" -o app.zip

Wget 下载

Linux 和 macOS 用户也可以使用 wget：

# 基本下载 wget "https://your-domain.vercel.app/github.com/owner/repo/archive/refs/heads/main.zip" -O repo.zip # 断点续传 wget -c "https://your-domain.vercel.app/github.com/owner/repo/archive/refs/heads/main.zip" -O repo.zip # 限速下载（500KB/s） wget --limit-rate=500k "https://your-domain.vercel.app/github.com/owner/repo/archive/refs/heads/main.zip" -O repo.zip

Python 下载

使用 Python 的 requests 库下载：

import requests url = "https://your-domain.vercel.app/github.com/owner/repo/archive/refs/heads/main.zip" r = requests.get(url, stream=True) r.raise_for_status() with open("repo.zip", "wb") as f: for chunk in r.iter_content(chunk_size=8192): f.write(chunk) print("下载完成！")

使用 urllib（无需安装第三方库）

import urllib.request url = "https://your-domain.vercel.app/github.com/owner/repo/archive/refs/heads/main.zip" urllib.request.urlretrieve(url, "repo.zip") print("下载完成！")

PowerShell 下载

Windows 用户可以使用 PowerShell：

# PowerShell 5.1+ Invoke-WebRequest -Uri "https://your-domain.vercel.app/github.com/owner/repo/archive/refs/heads/main.zip" -OutFile "repo.zip" # PowerShell 7+ Invoke-RestMethod -Uri "https://your-domain.vercel.app/github.com/owner/repo/archive/refs/heads/main.zip" -OutFile "repo.zip" # 显示进度条 $url = "https://your-domain.vercel.app/github.com/owner/repo/archive/refs/heads/main.zip" $webClient = New-Object System.Net.WebClient $webClient.DownloadFile($url, "repo.zip")

浏览器下载

直接在浏览器地址栏输入代理 URL 即可下载：

  1. 打开浏览器，在地址栏输入：https://your-domain.vercel.app/github.com/owner/repo/archive/refs/heads/main.zip
  2. 浏览器会自动下载 zip 文件
  3. 也可以通过仓库页面右下角的绿色"⬇️ 下载源码"按钮一键下载

批量下载

下载一个仓库的所有 Release 附件：

# 使用 API 获取 Release 列表，然后批量下载 # 第一步：获取所有 Release 的下载链接 curl "https://your-domain.vercel.app/api.github.com/repos/owner/repo/releases" | jq '.[].assets[].browser_download_url' # 第二步：逐个下载（Bash 脚本） for url in $(curl -s "https://your-domain.vercel.app/api.github.com/repos/owner/repo/releases" | jq -r '.[].assets[].browser_download_url'); do filename=$(basename "$url") echo "Downloading $filename ..." curl -L "$url" -o "$filename" done

速度对比

以下是使用代理前后的下载速度参考（实际速度取决于你的网络环境）：

场景直连 GitHub通过 Vercel 代理
Archive 下载（小仓库 < 10MB）~200 KB/s~2-5 MB/s
Archive 下载（大仓库 > 100MB）经常超时~5-10 MB/s
Release 附件（50MB）~500 KB/s~5-10 MB/s
Raw 单文件~1 MB/s~3-8 MB/s
aria2c 多线程（16 线程）~2 MB/s~15-30 MB/s
💡 提示：速度提升效果因地区和网络环境而异。Vercel 的边缘节点通常比直连 GitHub 有更好的路由优化。
