aria2c 多线程下载

aria2c 是一款轻量级的多协议、多线程下载工具，配合 GitHub 代理可以实现极速下载。

安装 aria2c

平台安装命令
macOS (Homebrew)brew install aria2
Ubuntu / Debiansudo apt-get install aria2
CentOS / RHELsudo yum install aria2
Arch Linuxsudo pacman -S aria2
Windows (Scoop)scoop install aria2
Windows (Chocolatey)choco install aria2
Windows (Winget)winget install aria2

基本用法

最简单的用法——下载一个文件：

aria2c "https://your-domain.vercel.app/github.com/owner/repo/archive/refs/heads/main.zip"

多线程 + 断点续传（推荐）：

aria2c -x 16 -s 16 -c "https://your-domain.vercel.app/github.com/owner/repo/archive/refs/heads/main.zip"

指定输出文件名：

aria2c -x 16 -s 16 -c -o my-repo.zip "https://your-domain.vercel.app/github.com/owner/repo/archive/refs/heads/main.zip"

参数详解

参数含义推荐值
-x N每个服务器的最大连接数16
-s N文件分片数16
-c断点续传始终开启
-o name指定输出文件名可选
-d dir指定输出目录可选
--max-tries=N最大重试次数30
--retry-wait=N重试间隔（秒）5
--timeout=N连接超时（秒）30
--max-concurrent-downloads=N最大并发下载数3
--min-split-size=N最小分片大小1M
--file-allocation=none文件预分配策略none（Vercel 不需要）
-q安静模式（不输出日志）可选
-v详细日志调试时用

配置文件

创建 ~/.aria2/aria2.conf 配置文件，避免每次输入长命令：

# ~/.aria2/aria2.conf # 基本设置 max-concurrent-downloads=3 continue=true max-connection-per-server=16 split=16 min-split-size=1M # 超时和重试 timeout=30 max-tries=30 retry-wait=5 # 文件分配 file-allocation=none # 日志 log-level=notice quiet=false # 代理设置（可选，如果你有 HTTP 代理） # http-proxy=http://127.0.0.1:7890 # https-proxy=http://127.0.0.1:7890 # 禁用 IPv6（某些网络下 IPv6 不稳定） disable-ipv6=true # 用户代理（避免被 GitHub 限速） user-agent=Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36

使用配置文件启动：

aria2c --conf-path=~/.aria2/aria2.conf "https://your-domain.vercel.app/github.com/owner/repo/archive/refs/heads/main.zip"

批量下载

方式一：URL 列表文件

创建 urls.txt：

# urls.txt https://your-domain.vercel.app/github.com/owner/repo/archive/refs/heads/main.zip https://your-domain.vercel.app/github.com/owner/repo/releases/download/v1.0/app-linux.zip https://your-domain.vercel.app/github.com/owner/repo/releases/download/v1.0/app-windows.zip https://your-domain.vercel.app/github.com/owner/repo/releases/download/v1.0/app-macos.zip

一行命令全部下载：

aria2c -x 16 -s 16 -c -i urls.txt

方式二：结合 GitHub API 自动获取 Release 链接

# 获取所有 Release 下载链接并保存 curl -s "https://your-domain.vercel.app/api.github.com/repos/owner/repo/releases" \ | jq -r '.[].assets[].browser_download_url' > urls.txt # 使用 aria2c 批量下载 aria2c -x 16 -s 16 -c -i urls.txt

方式三：Shell 脚本循环

#!/bin/bash # batch-download.sh DOMAIN="https://your-domain.vercel.app" REPO_PATH="/github.com/owner/repo" # 下载多个分支 for branch in main master develop; do aria2c -x 16 -s 16 -c \ -o "${branch}.zip" \ "${DOMAIN}${REPO_PATH}/archive/refs/heads/${branch}.zip" done

速度对比

下载方式平均速度稳定性
浏览器直连~200 KB/s经常超时
cURL 单线程~500 KB/s中等
Wget 单线程~500 KB/s中等
aria2c 4 线程~2-5 MB/s良好
aria2c 8 线程~5-10 MB/s良好
aria2c 16 线程~10-30 MB/s优秀
aria2c 32 线程~15-40 MB/s可能触发限速
💡 建议：16 线程是性价比最高的选择。超过 16 线程可能不会明显提速，反而可能触发 GitHub 的速率限制。

实用技巧

1. 一行命令下载并解压

aria2c -x 16 -s 16 -c -o repo.zip "URL" && unzip -q repo.zip && rm repo.zip

2. 后台下载 + 日志

aria2c -x 16 -s 16 -c -d ~/Downloads "URL" > ~/Downloads/aria2.log 2>&1 &

3. 下载完成后通知（macOS）

aria2c -x 16 -s 16 -c "URL" && osascript -e 'display notification "下载完成" with title "aria2c"'

4. 定时清理旧文件

# 删除 7 天前的下载文件 find ~/Downloads -name "*.zip" -mtime +7 -delete

5. 一键下载脚本模板

#!/bin/bash # quick-dl.sh - 一键下载 GitHub 仓库 # 用法: ./quick-dl.sh owner/repo [branch] DOMAIN="https://your-domain.vercel.app" REPO="${1:-vercel/next.js}" BRANCH="${2:-main}" URL="${DOMAIN}/github.com/${REPO}/archive/refs/heads/${BRANCH}.zip" FILENAME="$(echo ${REPO} | tr '/' '-')-${BRANCH}.zip" echo "📦 正在下载 ${REPO} (${BRANCH})..." aria2c -x 16 -s 16 -c -o "${FILENAME}" "${URL}" if [ $? -eq 0 ]; then echo "✅ 下载完成: ${FILENAME}" echo "📂 文件大小: $(du -h ${FILENAME} | cut -f1)" else echo "❌ 下载失败" exit 1 fi
