🚀 快速开始

只需 3 步，5 分钟内把 GitHub Proxy 部署到 Vercel，立刻享受高速下载。

前置要求

  • 一个 GitHub 账号
  • 一个 Vercel 账号（推荐用 GitHub 登录）
  • 本地安装了 Git（可选，也可用网页操作）

第一步：克隆项目

将项目克隆到你的 GitHub 账号下：

git clone https://github.com/tanle-mtr/vercel-proxy.git
cd vercel-proxy

如果你 Fork 了项目，把 URL 替换成你自己的仓库地址。

第二步：导入 Vercel

  1. 打开 vercel.com/new
  2. 点击 Import Project，选择刚克隆的仓库
  3. Framework Preset 留空（不需要选）
  4. Build Command 留空
  5. Output Directory 留空
  6. 点击 Deploy

💡 提示

第一次部署大约需要 30-60 秒。部署完成后，Vercel 会给你一个形如 xxx.vercel.app 的域名。

第三步：开始使用

部署完成后，直接在浏览器访问：

https://你的域名.vercel.app/github.com/vercel/next.js

你会看到 GitHub 仓库页面，右下角有一个绿色的 "⬇️ 下载源码" 按钮。

验证部署

在终端运行以下命令，确认一切正常：

# 导航页（应返回 200）
curl "https://你的域名.vercel.app/"

# 仓库页面（应返回 200）
curl -I "https://你的域名.vercel.app/github.com/vercel/next.js"

# 下载源码
curl -L "https://你的域名.vercel.app/github.com/vercel/next.js/archive/refs/heads/canary.zip" -o next.zip
