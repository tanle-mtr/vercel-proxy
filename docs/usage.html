使用方式

GitHub 代理支持多种使用场景，本文档详细介绍每种场景的 URL 格式和示例。

URL 格式

所有请求都遵循同一个模式：

https://你的域名/目标域名/路径

其中 目标域名 是白名单内的 GitHub 域名，路径 是该域名下的实际路径。

目标域名用途示例
github.com仓库页面、Release、Archive、Gist/github.com/vercel/next.js
api.github.comGitHub REST API/api.github.com/repos/vercel/next.js
raw.githubusercontent.com原始文件直链/raw.githubusercontent.com/owner/repo/main/file.txt
codeload.github.comArchive 打包下载/codeload.github.com/owner/repo/zip/main
objects.githubusercontent.comRelease 附件对象存储/objects.githubusercontent.com/...
avatars.githubusercontent.com用户头像/avatars.githubusercontent.com/...
camo.githubusercontent.com图片缩略图（Camo 代理）/camo.githubusercontent.com/...
gist.github.comGist 页面与 Raw 文件/gist.github.com/owner/abc123
github.githubassets.comGitHub 静态资源（CSS/JS）/github.githubassets.com/...
user-images.githubusercontent.com用户上传图片（README 等）/user-images.githubusercontent.com/...
private-user-images.githubusercontent.com私有用户图片/private-user-images.githubusercontent.com/...

仓库浏览

在浏览器中直接访问 GitHub 仓库：

https://你的域名/github.com/owner/repo

示例：

  • https://your-domain.vercel.app/github.com/vercel/next.js
  • https://your-domain.vercel.app/github.com/torvalds/linux
  • https://your-domain.vercel.app/github.com/microsoft/vscode
💡 提示：页面右下角会自动出现绿色"⬇️ 下载源码"按钮，点击即可下载当前分支的 zip 压缩包。

Archive 下载

下载整个仓库的源码压缩包：

https://你的域名/github.com/owner/repo/archive/refs/heads/branch.zip

示例：

# 下载 main 分支 curl -L "https://your-domain.vercel.app/github.com/vercel/next.js/archive/refs/heads/main.zip" -o nextjs.zip # 下载 master 分支 curl -L "https://your-domain.vercel.app/github.com/torvalds/linux/archive/refs/heads/master.zip" -o linux.zip # 下载指定 tag curl -L "https://your-domain.vercel.app/github.com/vercel/next.js/archive/refs/tags/v14.0.0.zip" -o nextjs-v14.zip

Release 下载

下载 GitHub Release 中发布的附件：

https://你的域名/github.com/owner/repo/releases/download/tag/filename

示例：

# 下载 Release 附件 curl -L "https://your-domain.vercel.app/github.com/owner/repo/releases/download/v1.0.0/app-linux-amd64.zip" -o app.zip

Raw 文件

直接获取单个文件的原始内容：

https://你的域名/raw.githubusercontent.com/owner/repo/branch/path/to/file

示例：

# 获取 package.json curl "https://your-domain.vercel.app/raw.githubusercontent.com/vercel/next.js/canary/package.json" # 获取 README curl "https://your-domain.vercel.app/raw.githubusercontent.com/vercel/next.js/canary/README.md"

API 访问

通过代理访问 GitHub REST API：

# 获取仓库信息 curl "https://your-domain.vercel.app/api.github.com/repos/vercel/next.js" # 获取文件树 curl "https://your-domain.vercel.app/api.github.com/repos/vercel/next.js/contents/" # 获取 Issues curl "https://your-domain.vercel.app/api.github.com/repos/vercel/next.js/issues?state=open"

Git 集成

你可以把代理域名当作 GitHub 的镜像来用：

# Clone 仓库 git clone https://your-domain.vercel.app/github.com/vercel/next.js # 添加为远程仓库 git remote add proxy https://your-domain.vercel.app/github.com/owner/repo # 拉取指定分支 git fetch proxy main
⚠️ 注意：Git 操作（clone/push/fetch）的可用性取决于 Vercel 的请求体大小限制（约 4.5MB）。大仓库建议使用 GitHub 原生地址。

下载按钮

当你通过浏览器访问仓库页面时（如 /github.com/owner/repo），页面右下角会自动出现一个绿色按钮：

⬇️ 下载源码 (main.zip)

按钮特性：

  • 固定在右下角（position: fixed），滚动页面不消失
  • 自动识别当前分支名（默认 main，支持 master 等）
  • 点击直接下载当前分支的 zip 压缩包
  • 层级最高（z-index: 99999），不会被页面元素遮挡
