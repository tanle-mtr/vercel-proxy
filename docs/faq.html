常见问题 (FAQ)

汇总用户最常问的问题，快速找到答案。

❓ 为什么 GitHub 网页加载不全？文件树不显示？

答：这是 Vercel Functions 的固有局限。GitHub 是重度 SPA（单页应用），它通过 JavaScript 动态调用 api.github.com 获取文件树数据。虽然我们注入了 fetch 和 XMLHttpRequest 劫持脚本，但 GitHub 的前端代码可能使用：

  • Service Worker — 在独立线程运行，无法被页面脚本劫持
  • 动态 import() — 模块加载走独立通道
  • eval() 拼接的 URL — 运行时才生成，静态替换抓不到

解决方案：

  • ✅ 下载需求 → 本代理完美胜任（Archive/Release/Raw）
  • ✅ 浏览需求 → 使用 github.com 原生访问
  • ✅ 完美反代 → 迁移到 Cloudflare Workers（边缘层改写，无需 JS 劫持）

❓ 下载速度慢怎么办？

答：使用 aria2c 多线程下载，速度可提升 10-50 倍：

aria2c -x 16 -s 16 -c "https://your-domain.vercel.app/github.com/owner/repo/archive/refs/heads/main.zip"

另外确认：

  • 你所在网络到 Vercel 边缘节点的路由是否通畅（Vercel 在国内部分地区路由不佳）
  • 是否触发了 GitHub 的速率限制（见 限制）
  • Vercel 月带宽是否用完（Hobby 100GB/月）

❓ 能代理私有仓库吗？

答：可以，但需要配置 GitHub Token。在 Vercel Dashboard → Settings → Environment Variables 添加：

变量名值
GITHUB_TOKEN你的 Personal Access Token（需要 repo 权限）

然后在 proxy.js 中添加：

if (process.env.GITHUB_TOKEN) { headers['Authorization'] = `Bearer ${process.env.GITHUB_TOKEN}`; }

❓ 支持 Git Clone 吗？

答：理论上支持，但实际体验取决于仓库大小：

  • ✅ 小仓库（< 50MB）：git clone https://your-domain.vercel.app/github.com/owner/repo 可以成功
  • ⚠️ 大仓库（> 100MB）：可能因 Vercel 10 秒超时中断
  • ❌ 超大仓库（> 500MB）：不建议通过代理 clone

建议：clone 用原生 GitHub 地址，下载 Release/Archive 用代理。

❓ 会泄露我的 IP 吗？

答：不会。所有请求都经过 Vercel 的边缘节点，目标服务器（GitHub）看到的 IP 是 Vercel 的出口 IP，不是你的真实 IP。但要注意：

  • 如果你在请求中带了 Authorization: Bearer TOKEN，Token 会经过 Vercel 服务器（Vercel 不会记录，但理论上可见）
  • 建议使用环境变量存储 Token，不要在 URL 中传递

❓ 能部署到国内服务器吗？

答：可以，但需要一台有公网 IP 的服务器：

  • 将 api/proxy.js 改写为 Express.js 中间件
  • 部署到阿里云/腾讯云轻量服务器
  • 优点：国内访问快、无 Vercel 额度限制
  • 缺点：需要自己维护服务器、HTTPS 证书

❓ 为什么大文件下载失败？

答：常见原因和解决方案：

原因解决方案
Vercel 10 秒超时（Hobby）用 aria2c 多线程分片下载
文件 > 4.5MB 请求体限制仅影响上传，下载不受影响
GitHub 限速（未认证 60次/小时）配置 GITHUB_TOKEN 提升到 5000次/小时
Vercel 月带宽用完升级 Pro 或等下月重置

❓ 如何监控用量？

# Vercel CLI 查看用量 vercel inspect # 查看实时日志 vercel logs --follow # 查看 GitHub API 剩余额度 curl "https://your-domain.vercel.app/api.github.com/rate_limit" | jq '.'

也可以在 Vercel Dashboard → Analytics 查看可视化用量图表。

❓ 可以商用吗？

答：可以。本项目使用 MIT License，允许商用。但需要注意：

  • Vercel Hobby 计划仅供个人使用，商用需升级 Pro（$20/月/人）
  • GitHub API 的使用需遵守 GitHub Acceptable Use Policies
  • 不要将代理用于下载盗版内容或恶意软件

❓ 支持 WebSocket 吗？

答：不支持。Vercel Functions 目前不支持 WebSocket 连接。如果你需要代理 WebSocket（如 GitHub Codespaces），需要使用 Cloudflare Workers 或自建服务器。

❓ 如何更新代理代码？

两种方式：

方式一：GitHub 推送（推荐）

# 修改代码后 git add . git commit -m "fix: 修复 xxx 问题" git push origin main # Vercel 自动检测并重新部署

方式二：Vercel Dashboard 在线编辑

  1. 打开 Vercel Dashboard → 你的项目
  2. 点击左侧 Files
  3. 找到 api/proxy.js，点击编辑
  4. 修改后点击 Save，自动部署

❓ 为什么有时返回 403？

答：403 可能来自两个地方：

来源原因解决方案
本代理请求的域名不在白名单中检查 URL 格式是否正确
GitHub触发了 GitHub 的速率限制或 IP 封禁配置 GITHUB_TOKEN 或等待重置
GitHub请求了私有仓库但没有认证添加 Authorization 头
