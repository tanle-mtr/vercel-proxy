查看当前速率限制

# 未认证 curl -I "https://your-domain.vercel.app/api.github.com/users/octocat" # 带 Token curl -H "Authorization: Bearer YOUR_TOKEN" \ "https://your-domain.vercel.app/api.github.com/users/octocat" # 查看速率限制状态 curl "https://your-domain.vercel.app/api.github.com/rate_limit"

响应头中关注：

  • X-RateLimit-Limit — 当前限额
  • X-RateLimit-Remaining — 剩余次数
  • X-RateLimit-Reset — 重置时间（Unix 时间戳）

请求体大小

Vercel Functions 对请求体有 4.5MB 的限制。如果你需要代理 Git push 等操作，大文件会失败。

⚠️ 注意：对于大文件上传，建议使用 GitHub 原生地址，或者考虑 Cloudflare R2 + Workers 的方案。

超时限制

场景Hobby 超时Pro 超时
普通请求10 秒300 秒
流式响应10 秒300 秒
上游连接10 秒300 秒

对于大文件下载，10 秒可能不够。建议：

  • 使用 aria2c 多线程下载（每个分片独立请求，不受超时影响）
  • 升级到 Pro 计划（300 秒足够大多数场景）
  • 对超过 50MB 的文件，考虑直接使用 GitHub 原生地址

优化建议

1. 启用缓存减少重复请求

// 在 proxy.js 中缓存静态资源 const cache = new Map(); async function cachedFetch(url, headers) { const key = url; if (cache.has(key)) { return cache.get(key); } const res = await fetch(url, { headers, redirect: 'manual' }); const buf = await res.arrayBuffer(); const data = { status: res.status, headers: res.headers, body: buf }; cache.set(key, data); // 5 分钟后过期 setTimeout(() => cache.delete(key), 5 * 60 * 1000); return data; }

2. 大文件用 aria2c 分片下载

每个分片是一个独立的 HTTP 请求，Vercel 的 10 秒超时只作用于单个分片，不会中断整个下载。

aria2c -x 16 -s 16 --max-file-size=50M "URL"

3. 监控用量

# 查看 Vercel 用量 vercel inspect # 查看 GitHub API 用量 curl "https://your-domain.vercel.app/api.github.com/rate_limit" | jq '.'

4. 设置用量告警

在 Vercel Dashboard → Settings → Notifications 中开启用量告警，当月用量达到 80% 时自动通知你。

💡 总结：Hobby 计划对个人使用完全够用（100 万次请求 + 100GB 带宽）。如果是团队使用或高频下载，建议升级 Pro 或考虑 Cloudflare Workers（每天 10 万次免费请求，无带宽限制）。
