自定义域名

将代理绑定到自己的域名（如 proxy.example.com），更短、更好记、更专业。

Vercel DNS 配置（推荐）

最简单的方式——把域名直接交给 Vercel 管理：

  1. 打开 Vercel Dashboard → 你的项目 → Settings → Domains
  2. 输入你的域名（如 gh.example.com），点击 Add
  3. Vercel 会提示你设置 NS 记录，将域名的 Nameserver 改为 Vercel 的：
    • ns1.vercel-dns.com
    • ns2.vercel-dns.com
  4. 在域名商后台修改 NS 记录（通常 5 分钟 - 48 小时生效）
  5. 回到 Vercel，等待状态变为 Valid Configuration

CNAME 配置

如果你不想把 DNS 交给 Vercel，可以用 CNAME：

# DNS 记录配置 类型: CNAME 名称: gh (或 @ 代表根域名) 值: cname.vercel-dns.com TTL: 600

然后在 Vercel Dashboard → Settings → Domains 中添加该域名。

A 记录配置

Vercel 也支持 A 记录（不推荐，因为 IP 可能变化）：

# DNS 记录配置 类型: A 名称: gh (或 @) 值: 76.76.21.21 TTL: 600
⚠️ 注意：Vercel 的 IP 地址可能会变更。CNAME 方式更可靠，推荐使用 CNAME 或 NS 委托。

HTTPS 证书

Vercel 会自动为你的自定义域名申请和续签 TLS 证书（Let's Encrypt），无需任何手动操作。

  • 证书有效期：90 天，自动续签
  • 支持通配符域名（*.example.com）
  • 自动启用 HTTP/2 和 HTTP/3 (QUIC)

验证配置

配置完成后，用以下命令验证：

# 检查 DNS 解析 nslookup gh.example.com # 应该返回 Vercel 的 IP # 检查 HTTPS 证书 curl -I https://gh.example.com/ # 应该返回 HTTP/2 200 # 检查代理功能 curl -I https://gh.example.com/github.com/vercel/next.js # 应该返回 HTTP/2 200

常见域名商指南

Cloudflare

  1. 登录 Cloudflare → 添加站点
  2. 将域名 NS 改为 Cloudflare 的 Nameserver
  3. 在 DNS 面板添加 CNAME 记录指向 cname.vercel-dns.com
  4. 重要：将代理状态设为 DNS Only（灰色云朵），否则 Cloudflare 会缓存导致问题
  5. 在 Vercel 添加域名

阿里云万网

  1. 登录阿里云控制台 → 域名管理
  2. 选择域名 → DNS 修改
  3. 添加 CNAME 记录：主机记录 gh，记录值 cname.vercel-dns.com
  4. 或将 NS 改为 Vercel 的 Nameserver

腾讯云 DNSPod

  1. 登录腾讯云控制台 → DNSPod
  2. 选择域名 → 添加记录
  3. CNAME 记录：主机 gh，值 cname.vercel-dns.com

Namecheap

  1. 登录 Namecheap → Domain List
  2. 找到域名 → Advanced DNS
  3. 添加 CNAME 记录：Host gh，Value cname.vercel-dns.com
💡 提示：绑定自定义域名后，记得更新文档和脚本中的域名引用。建议同时保留 Vercel 默认域名作为备份。
