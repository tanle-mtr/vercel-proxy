部署指南

将 GitHub 代理部署到 Vercel，5 分钟即可完成。

前置要求

  • 一个 GitHub 账号
  • 一个 Vercel 账号（推荐用 GitHub 登录）
  • 本地安装 Git（可选，也可用网页操作）

Vercel 部署

方式一：网页导入（推荐）

  1. 打开 vercel.com/new
  2. 点击 Import Project，选择刚克隆的仓库
  3. Framework Preset 选择 Other（不需要选）
  4. Build Command 留空
  5. Output Directory 留空
  6. 点击 Deploy

💡 提示

第一次部署大约需要 30-60 秒。部署完成后，Vercel 会给你一个形如 xxx.vercel.app 的域名。

方式二：Vercel CLI

# 安装 Vercel CLI npm install -g vercel # 进入项目目录 cd vercel-proxy # 部署到生产环境 vercel --prod

方式三：GitHub Actions 自动部署

在仓库根目录创建 .github/workflows/deploy.yml：

name: Deploy to Vercel on: push: branches: [main] jobs: deploy: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - uses: amondnet/vercel-action@v25 with: vercel-token: ${{ secrets.VERCEL_TOKEN }} vercel-org-id: ${{ secrets.ORG_ID }} vercel-project-id: ${{ secrets.PROJECT_ID }}

自定义域名

在 Vercel Dashboard → Settings → Domains 中添加自定义域名：

  1. 登录 Vercel Dashboard
  2. 进入项目 → Settings → Domains
  3. 输入你的域名（如 proxy.example.com）
  4. 按照提示配置 DNS（添加 CNAME 记录指向 cname.vercel-dns.com）

环境变量

当前版本不需要环境变量。如需添加访问控制：

# 在 Vercel Dashboard → Settings → Environment Variables 添加： # 方式一：IP 白名单（多个 IP 用逗号分隔） ALLOWED_IPS=1.2.3.4,5.6.7.8 # 方式二：Token 认证 PROXY_TOKEN=a3f8b2c9e1d4f7a6b5c8e9d2f1a4b7c # 方式三：GitHub Token（提高 API 速率限制） GITHUB_TOKEN=ghp_xxxxxxxxxxxx

GitHub Pages（文档站点）

如需部署文档站点，创建 .github/workflows/pages.yml：

name: Deploy Documentation on: push: branches: [main] paths: - 'gh-proxy-docs/**' permissions: contents: read pages: write id-token: write jobs: deploy: environment: name: github-pages url: ${{ steps.deployment.outputs.page_url }} runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - uses: actions/configure-pages@v5 - uses: actions/upload-pages-artifact@v3 with: path: 'gh-proxy-docs' - id: deployment uses: actions/deploy-pages@v4
💡 提示：文档站点会自动部署到 https://tanle-mtr.github.io/vercel-proxy/（需开启 GitHub Pages）。

验证部署

部署完成后，运行以下命令验证：

# 导航页（应返回 200） curl "https://你的域名.vercel.app/" # 仓库页面（应返回 200） curl -I "https://你的域名.vercel.app/github.com/vercel/next.js" # 下载源码 curl -L "https://你的域名.vercel.app/github.com/vercel/next.js/archive/refs/heads/canary.zip" -o next.zip # API 代理 curl "https://你的域名.vercel.app/api.github.com/repos/vercel/next.js"

🎉 完成！

你的 GitHub 代理已经部署成功，可以开始使用了！
