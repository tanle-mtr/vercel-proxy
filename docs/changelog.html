v1.0.0 - 2026-07-30（初始发布）

🎉 初始发布

核心功能

  • ✅ GitHub 仓库代理（网页浏览 + 下载）
  • ✅ Release 附件高速下载
  • ✅ Archive 打包下载（zip/tar.gz）
  • ✅ Raw 文件直链
  • ✅ GitHub REST API 代理
  • ✅ 右下角"下载源码"按钮自动注入

技术特性

  • ✅ 零依赖（使用 Vercel 内置 fetch）
  • ✅ CommonJS 兼容 Vercel Node.js 运行时
  • ✅ HTML 文本替换（URL 代理化）
  • ✅ 重定向 Location 自动改写
  • ✅ CORS 开放（Access-Control-Allow-Origin: *）
  • ✅ CSP 自动清除
  • ✅ 流式传输（非 HTML 内容）
  • ✅ fetch + XMLHttpRequest 前端劫持

安全

  • ✅ 白名单域名校验
  • ✅ 非白名单路径返回导航页（不报错）
  • ✅ 请求头清理（Host/Origin/Referer 重写）
  • ✅ 危险响应头删除（CSP/clear-site-data）

文档

  • ✅ 14 个文档页面
  • ✅ 明暗双主题
  • ✅ 代码一键复制
  • ✅ 响应式布局
  • ✅ MIT License

🐛 已知问题

  • ⚠️ GitHub SPA 文件树动态加载可能不完整（GitHub 前端过于复杂）
  • ⚠️ Service Worker 和动态 import 无法被前端劫持覆盖
  • ⚠️ 大文件（>100MB）下载可能触发 Vercel 10 秒超时（Hobby 计划）

如何贡献

  1. Fork 本仓库
  2. 创建分支：git checkout -b feature/your-feature
  3. 提交改动：git commit -am 'Add some feature'
  4. 推送分支：git push origin feature/your-feature
  5. 提交 Pull Request

贡献指南

  • 代码风格：使用 2 空格缩进
  • 提交信息：使用 Conventional Commits 格式
  • 测试：确保修改后通过 Vercel 部署测试
  • 文档：如果改了功能，请同步更新文档
💡 提示：如果你有好的想法或发现了 Bug，欢迎提 Issue 或 PR！
