扩展白名单

默认配置只代理 GitHub 相关域名。本文档教你如何安全地添加更多域名。

⚠️ 安全警告：每添加一个域名，就等于给代理开放了一个新的出口。只添加你信任的、合法的域名。不要添加开放代理或可能被滥用的服务。

添加新域名

编辑 api/proxy.js，找到 ALLOWED_PREFIXES 数组：

const ALLOWED_PREFIXES = [ 'github.com', 'api.github.com', 'raw.githubusercontent.com', 'codeload.github.com', // 👇 在这里添加新域名 'example.com' ];

添加多个域名

const ALLOWED_PREFIXES = [ 'github.com', 'api.github.com', 'raw.githubusercontent.com', 'codeload.github.com', // 新增：npm 镜像 'registry.npmjs.org', // 新增：Python PyPI 'pypi.org', 'files.pythonhosted.org', // 新增：Docker Hub 'registry-1.docker.io', // 新增：Hugging Face 'huggingface.co', 'cdn-lfs.huggingface.co' ];

通配符匹配

当前实现使用精确匹配和子域名匹配：

// isAllowedHost 函数 function isAllowedHost(host) { return ALLOWED_PREFIXES.some(d => host === d || host.endsWith('.' + d)); }

这意味着：

  • github.com → ✅ 匹配
  • api.github.com → ✅ 匹配（子域名）
  • gist.github.com → ✅ 匹配（如果在白名单中）
  • evil.github.com → ✅ 也会匹配（注意安全风险）

更严格的匹配（可选）

如果只想允许特定子域名：

function isAllowedHost(host) { // 只匹配精确值，不匹配子域名 return ALLOWED_PREFIXES.includes(host); }

测试新域名

添加域名后，部署并测试：

# 测试新添加的域名是否生效 curl -I "https://your-domain.vercel.app/registry.npmjs.org/express" # 测试重定向 curl -I "https://your-domain.vercel.app/pypi.org/project/requests/" # 测试 404（不存在的路径） curl -I "https://your-domain.vercel.app/registry.npmjs.org/nonexistent-pkg"

测试脚本

#!/bin/bash # test-domains.sh - 批量测试白名单域名 DOMAIN="https://your-domain.vercel.app" declare -A TESTS=( ["github.com"]="/vercel/next.js" ["api.github.com"]="/repos/vercel/next.js" ["raw.githubusercontent.com"]="/vercel/next.js/canary/package.json" ["registry.npmjs.org"]="/express" ) for host in "${!TESTS[@]}"; do path="${TESTS[$host]}" url="${DOMAIN}/${host}${path}" code=$(curl -s -o /dev/null -w "%{http_code}" "$url") echo "${host}: HTTP ${code}" done

移除域名

只需从 ALLOWED_PREFIXES 数组中删除对应行，重新部署即可。

💡 提示：移除域名后，之前生成的代理链接会返回导航页（200），不会报错。
