安全

代理是一把双刃剑。本文档帮你把风险降到最低。

⚠️ 重要提醒：一个开放的代理可能被他人用于绕过网络限制、下载恶意软件或发起攻击。请务必配置访问控制！

潜在风险

风险描述严重程度
被滥用为开放代理任何人都能通过你的域名访问 GitHub🔴 高
带宽耗尽恶意用户大量下载，消耗 100GB 月额度🟡 中
请求数耗尽被刷请求，超过 100 万次/月🟡 中
法律连带责任他人通过代理下载侵权内容🔴 高

IP 白名单

最简单有效的安全措施——只允许你的 IP 使用代理。

方式一：Vercel Edge Middleware（推荐）

创建 middleware.js 放在项目根目录：

// middleware.js const ALLOWED_IPS = [ '1.2.3.4', // 你的家庭 IP '5.6.7.8', // 你的办公 IP '::1', // IPv6 localhost ]; export function middleware(req) { const ip = req.headers.get('x-forwarded-for') || req.headers.get('x-real-ip') || ''; const clientIp = ip.split(',')[0].trim(); if (!ALLOWED_IPS.includes(clientIp)) { return new Response('Access Denied', { status: 403 }); } return new Response(null, { status: 200 }); } export const config = { matcher: '/:path*' };

方式二：在 proxy.js 中检查

// 在 handler 开头添加 const ALLOWED_IPS = ['1.2.3.4', '5.6.7.8']; const clientIp = (req.headers['x-forwarded-for'] || '').split(',')[0].trim(); if (!ALLOWED_IPS.includes(clientIp)) { return res.status(403).send('Access Denied'); }

获取你的公网 IP

# 方法一 curl ifconfig.me # 方法二 curl ipinfo.io/ip # 方法三（国内推荐） curl myip.ipip.net

Token 认证

更灵活的方案——用 Token 控制访问。

设置环境变量

在 Vercel Dashboard → Settings → Environment Variables 添加：

变量名值说明
PROXY_TOKEN一个长随机字符串如 a3f8b2c9e1d4f7a6b5c8e9d2f1a4b7c
GITHUB_TOKENGitHub Personal Access Token提高 API 速率限制

生成随机 Token

# 生成 32 字符随机 Token openssl rand -hex 16 # 或使用 Node.js node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

在 proxy.js 中验证 Token

// 在 handler 开头添加 const PROXY_TOKEN = process.env.PROXY_TOKEN; if (PROXY_TOKEN) { const authHeader = req.headers['authorization'] || ''; const urlToken = new URL(req.url, 'http://localhost').searchParams.get('token') || ''; const valid = authHeader === `Bearer ${PROXY_TOKEN}` || authHeader === `Token ${PROXY_TOKEN}` || urlToken === PROXY_TOKEN; if (!valid) { res.setHeader('WWW-Authenticate', 'Bearer realm="GitHub Proxy"'); return res.status(401).send('Unauthorized'); } }

使用 Token 访问

# Header 方式 curl -H "Authorization: Bearer a3f8b2c9e1d4f7a6b5c8e9d2f1a4b7c" \ "https://your-domain.vercel.app/github.com/owner/repo" # URL 参数方式 curl "https://your-domain.vercel.app/github.com/owner/repo?token=a3f8b2c9e1d4f7a6b5c8e9d2f1a4b7c" # aria2c 方式 aria2c --header="Authorization: Bearer a3f8b2c9e1d4f7a6b5c8e9d2f1a4b7c" \ "https://your-domain.vercel.app/github.com/owner/repo/archive/main.zip"

速率限制

防止单个 IP 消耗过多资源。

简单内存限速

// 在 proxy.js 顶部添加 const rateMap = new Map(); const RATE_LIMIT = 100; // 每窗口最大请求数 const WINDOW_MS = 60000; // 窗口时间（1 分钟） function checkRate(ip) { const now = Date.now(); const windowStart = now - WINDOW_MS; const requests = rateMap.get(ip) || []; const recent = requests.filter(t => t > windowStart); if (recent.length >= RATE_LIMIT) { return false; } recent.push(now); rateMap.set(ip, recent); return true; } // 在 handler 中调用 const clientIp = (req.headers['x-forwarded-for'] || '').split(',')[0].trim(); if (!checkRate(clientIp)) { return res.status(429).send('Too Many Requests'); }
⚠️ 注意：Vercel 是 Serverless 环境，内存中的 rateMap 在实例重启后会丢失。生产环境建议使用 Redis（如 Vercel KV 或 Upstash）。

使用 Upstash Redis（推荐生产方案）

// 安装依赖 npm install @upstash/redis // 在 proxy.js 中使用 import { Redis } from '@upstash/redis'; const redis = new Redis({ url: process.env.UPSTASH_REDIS_URL, token: process.env.UPSTASH_REDIS_TOKEN, }); async function checkRateUpstash(ip) { const key = `rate:${ip}`; const count = await redis.incr(key); if (count === 1) await redis.expire(key, 60); return count <= 100; }

内容过滤

防止代理被用于下载恶意内容。

文件类型白名单

const ALLOWED_EXTENSIONS = [ '.zip', '.tar', '.gz', '.tar.gz', '.tar.bz2', '.tar.xz', '.js', '.ts', '.json', '.md', '.txt', '.csv', '.png', '.jpg', '.jpeg', '.gif', '.svg', '.ico', '.pdf', '.doc', '.docx', '.xls', '.xlsx', '.py', '.rb', '.go', '.rs', '.java', '.c', '.cpp', '.h', '.css', '.html', '.xml', '.yaml', '.yml', '.toml' ]; function isAllowedFile(url) { const path = new URL(url).pathname.toLowerCase(); return ALLOWED_EXTENSIONS.some(ext => path.endsWith(ext)); }

文件大小限制

const MAX_FILE_SIZE = 500 * 1024 * 1024; // 500MB // 在收到响应头后检查 const contentLength = parseInt(upstreamRes.headers.get('content-length') || '0'); if (contentLength > MAX_FILE_SIZE) { return res.status(413).send(`File too large: ${contentLength} bytes > ${MAX_FILE_SIZE}`); }

应急响应

发现被滥用怎么办？

  1. 立即暂停项目：Vercel Dashboard → Settings → Danger Zone → Suspend Project
  2. 检查日志：找出异常 IP 和请求模式
  3. 添加 IP 白名单：只保留自己的 IP
  4. 更换 Token：如果使用了 Token 认证，立即轮换
  5. 重新部署：确认安全后恢复服务

一键紧急关闭脚本

#!/bin/bash # emergency-stop.sh - 紧急关闭代理 # 通过 Vercel API 删除所有域名绑定 VERCEL_TOKEN="your-vercel-token" PROJECT_ID="prj_xxxx" echo "🚨 正在紧急关闭代理..." # 获取所有域名 DOMAINS=$(curl -s "https://api.vercel.com/v6/projects/${PROJECT_ID}/domains" \ -H "Authorization: Bearer ${VERCEL_TOKEN}" | jq -r '.[].name') # 逐个删除域名绑定 for domain in $DOMAINS; do echo " 删除域名: $domain" curl -s -X DELETE "https://api.vercel.com/v6/projects/${PROJECT_ID}/domains/${domain}" \ -H "Authorization: Bearer ${VERCEL_TOKEN}" done echo "✅ 代理已关闭。请检查日志后手动恢复。"
💡 最佳实践：默认开启 IP 白名单或 Token 认证，不要部署完全开放的代理。定期检查 Vercel Dashboard 的用量统计，发现异常及时处理。
